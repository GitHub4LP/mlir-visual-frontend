# 可视化编程前端模型（主规范，第 21 轮重写，第 36 轮编号并与检验对齐）

本文件是**当前的规范性模型**：前端实现者只读它，就应当知道每种编辑要问哪一层、谁有权拒绝、代价多大、诊断和补全依据什么。
- 每条规范性条款带编号〔Mx.y〕。条款与实现、检验、证据的对照见 clauses.md，由 model/clauses_test.py 机械核对（编号双向一致、检验文件与标记存在、所引定律的等级不弱于条款声称的等级）。
- 各条定律的证据等级见 laws.md（A 外部语料 / B MLIR 差分 / C 自证 / D 定义 / ✗ 已否定）。机制覆盖见 coverage.md，门槛见 done.md。
- 第 1–4 轮的推导规则原文保留在 derivation-v3.md，作为历史参考。

## 0 定位与三条判据
- 前端 IR（VIR）是一门独立的语言，经 ⟦·⟧ 降到 MLIR。它要建模的是 MLIR 的**机制**，而不是 MLIR 的外壳。
- **(1) 覆盖**：MLIR 的每项机制都可以导入或降级，不能缺（coverage.md）。
- **(2) 组合律可靠**：每条有拒绝权或改写权的定律都要有 A/B 级证据（laws.md）。
- **(3) 指导性**：见 §4 的动作表。
- **“不弱于 MLIR”的可检验形式**：
  - 〔M0.1〕前端判定合法 ⇒ MLIR verifier 接受；有拒绝权的层不误拒；
  - 〔M0.2〕导入一个 MLIR 程序，语义不变；不能保证时给“未知”，不给事实；
  - 〔M0.3〕前端证明的改写 ⇒ 在 MLIR 语义下也是精化。
- 〔M0.4〕**“强于 MLIR”**只允许出现在 MLIR 没有对应物的地方，并且必须标成 D 级：编辑期的洞与部分图；结果类型相对选择（L26）；tensor 层无 UB 加降低守卫（L24）；增量与补全。
- 〔M0.5〕**外部真值有缺陷时**：模型按规范（LangRef/ODS）建模，不跟随缺陷；差分中的不一致只有经 A/B 隔断（同一输入、只去掉触发缺陷的形状、结果与模型一致）才可归因，否则仍计不一致。已归因：MLIR index 在 IW=32 的折叠（L50）、index CmpOp::canonicalize（L52）、truncf roundingmode 不生效（values §10.2）、LLVM AArch64 f16 fptosi→sitofp（values §11.3）。

## 1 对象
- 〔M1.1〕**Op = ⟨Schema, Impl⟩**。Impl 是 Primitive、Graph（复合）、External 三者之一。所有消费者只读 Schema；复合 op 的嵌套使用 ≡ 内联。
- **Schema** 的字段与来源：

| 字段 | 内容 | 原生 op 的来源 | 复合 op 的来源 | 级 | 条款 |
|---|---|---|---|---|---|
| 结构 | 区域种类/个数、终结子、后继、隔离、符号定义者/表/使用者 | ODS trait/interface 闭包（structure、symtab） | 推导：captures、free_syms、needs_ssacfg（L3–L5） | A（原生）/ B（复合） | M1.2 |
| 类型签名 | 端口约束 Pred 树、多态签名 | tblgen JSON 自动签名（L28/L29） | 有拒绝权的层逐节点判定（L25/L46/L47）；compsig 的符号 Φ 只用于呈现与端口投影（L27） | A / A | M1.3 |
| 属性 | 参数值域、必需性 | ODS 导入，值是 MLIR Attribute（L34、L35） | 使用点约束的合取（L10） | A / B | M1.4 |
| declared 义务 | C++ verify、开放接口、区域分支边 | 只有预言机能裁决（L43、L44） | 透明内联后交预言机 | A | M1.5 |
| 值层 | Sem / UB / Poison | 人工覆盖层，经 JIT 差分审计（§3） | 推导（L6） | B（原生，§3 所列子集；复合摘要的毒值依赖第 53 轮升 B，只限确定值方向） | M1.6 |
| 效应 | MemoryEffects 三元组 | ODS | compose_eff（L7） | B | M1.7 |
| caps | Speculatable、Pure 等 | 由上面各字段派生，不单独声明；对降低后的 MLIR 而言（含守卫与 L22 义务） | 同左 | B | M1.8 |

- 〔M1.9〕**复合 op 与原生 op 同构**：同一种 Schema、同一个 check。声明只能收窄，并且要经过检查（Φ_user ⊨ Φ_comp）。
- 〔M1.10〕**名字即语义身份**：按名字共享或按键缓存的项（洞、循环摘要、端口占位、ADT、Workspace 键），名字须单射编码全部语义来源，含全局语义开关（L54、L18′）。

## 2 分层与拒绝权
| 层 | 回答 | 权威 | 代价 | 拒绝权 | 条款 |
|---|---|---|---|---|---|
| 结构层 R1–R8、S1–S5 | 区域、块、支配、可见性、符号 | ODS 导入的结构 | 局部 O(1)；R5 按区域重建支配树；S2/S4 走反向索引 | 有（L39：Z2 误拒 0） | M2.1 |
| 自动签名 | 端口类型 | tblgen JSON | Φ 检查约 30 µs | 有（L29，A） | M2.2 |
| 属性层 | 参数、属性 | ODS + MLIR 属性解析器 | 微秒级 | 有（L34a，A） | M2.3 |
| 符号层 | 引用解析、使用义务 | ODS 接口 + _attrs | 反向索引 | 有（L36a，A） | M2.4 |
| 预言机（隔离单元） | 其余全部：C++ verify、开放接口、区域分支边 | MLIR verifier，同一提交 | 原生约 3–15 µs；本原型跨进程约 670 µs，命中缓存约 73 µs | 有，且是最终权威（L42，A） | M2.5 |
| 人工签名 typesig | 预言机不可用时的退路 | 人工 | — | **无**，只发警告（L33） | M2.6 |
| 值层 / 效应 / caps | 预览、可推测性、改写证明、补全分类 | 覆盖层与推导 | 查询为毫秒级 | **无**：不拒绝程序（必然 UB 的程序也合法），只提供事实与改写许可 | M2.7 |

- 〔M2.8〕**判定顺序**：结构 → 符号 → 自动签名与属性 → 预言机。前一层的拒绝即为终判；预言机只在符号层管不到的节点上补充拒绝（L30）。诊断经 Location 回映到节点（L31）。
- 〔M2.9〕**无结论是一等结果**：发射不忠实、不可送达、资源缺失、预言机崩溃时返回 None 并给警告，不能报成类型错误（L41）。

## 3 值层的语义
- 〔M3.1〕**iN**：位向量。add/sub/mul 回绕；nsw/nuw 溢出产生毒值；divui/divsi/remsi 除以 0 是 UB；毒值进入除数是 UB。
- 〔M3.2〕**index**：IW 位补码，结果回绕（L17″，A）。目标无关的事实要对 IW ∈ {32, 64} 都成立（L49）。面向 IW≠64 的目标时，先把 index 降为 iIW，再交给 MLIR 变换（L50）。
- 〔M3.3〕**语义参数**：节点带有值层不读的参数时，值层不给事实（L51）；导入的真实 IR 每个属性须翻译或登记为无关，否则 ⇒ 未知（L53）。
- 〔M3.4〕**tensor**：⟨extent, 元素, 元素毒值⟩。越界产生毒值而不是 UB（L24，D 级）；降低时对 extract/insert/dim/cast 插守卫，且须证明插守卫后的语义精化 core 语义（guards.plan），切片类与毒值下标判未知（values §13）。逐元素 arith 作用于 ranked 整数 tensor：形状不一致或任一元素 UB ⇒ UB（values §9.1–9.2）。浮点元素 tensor ⇒ 未知。
- 〔M3.5〕**浮点**：f16/bf16/f32/f64 按 IEEE-754（z3 FP），NaN 不区分载荷与符号——前提是没有观察 NaN 位的 op：bitcast f→i、copysign 判未知。remf = fmod；fastmath 只建 nnan/ninf，其余判未知；maxnumf/minnumf、truncf roundingmode 判未知（values §10）。
- 〔M3.6〕**math**：只登记降到正确舍入或精确 LLVM 内建的子集（absf、ceil/floor/trunc/round/roundeven、sqrt、fma、isnan、isfinite、absi、ctlz/cttz/ctpop）；超越函数、copysign、fpowi、isinf/isnormal 判未知（values §11）。
- 〔M3.7〕**精化判据**：src 不 UB ⇒ tgt 不 UB；src 非毒值 ⇒ tgt 值相同且非毒值。改写、fold、降级都用这同一个判据；外部校准是 MLIR 自己的变换（canonicalize、int-range-optimizations、sccp）在模型下必须是精化，且该变换本身要有 JIT 对照（L52）。
- 〔M3.8〕**循环**：摘要名 = 结构 + 语义开关，体内参数与捕获值都是实参（L18′）；不变式先做归纳检查，再作为公理（L19）；scf.for 越界步进是 UB（loops §8）。
- 〔M3.9〕**用户 ADT 与接口定律**：ADT 降级正确性 = 抽象函数下的精化（L11）；接口定律是定向精化（L12，值层）。毒值层：L6 第 53 轮升 B，ADT 降级后的毒值层第 55 轮外部化（values §14.2），都只检验了“确定值”方向；前端不得只凭“此处是毒值/UB”的结论做变换。

## 5 降级 ⟦·⟧ 与它的义务
- 〔M5.1〕⟦·⟧ 包含 pass 管线，不只是 IR 翻译。判据是 Sem(g) ⊑ Sem(pipeline(⟦g⟧))；资源性质（栈）也要经管线保持（M5.3）。反例：LICM 提升 tensor.extract，bufferize 之后变成无条件的 load（difftest/）。管线只能取钉定提交上经差分检验的白名单 pass（L55，values §15）；9bae84b0 上 scf-for-loop-peeling（lb > ub 时多执行一次）与 remove-dead-values（留下空操作数的调用）不在白名单里。
- 〔M5.2〕复合 op 有三种落地方式（内联进 Graph 区域时，体内可能有副作用的 op 次序未定义 ⇒ 未知，L56）：内联（透明，默认）；func + call（不透明）；IRDL op（不透明，有 MLIR 身份）。IRDL 只能表达 any/is/相等，所以不透明模式下使用点仍由前端用 Φ 判定（L48）。
- 〔M5.3〕内联要保持作用域：体内有自动作用域分配（ODS 导出的集合）时包一层 alloca_scope；有 memref 输出时判逃逸未建模、不发射；遇到自由符号时要判定两种模式下解析是否一致（L4）。降级管线在全部优化之后、方言降低之前把作用域语义落成 stacksave/stackrestore（lowering.lower_alloca_scopes），因为本提交 MLIR 的标准降低不尊重 scf.for 的作用域 trait，且降不下体内有控制流的结构化区域内 alloca_scope（closure §8.1）。
- 〔M5.4〕后端诊断通过 Location（节点 id）回映到节点（L31）。

## 6 当前已知的不足（非规范；按 clauses.md 的“缺口/部分”行处理）
- 值层复合摘要的毒值依赖（L6）第 53 轮升 B：毒值实参下的确定值经 JIT 外部化（values §14）；“是毒值/UB”方向是精化自由度，执行测不出，不能单独作为变换依据；caps（M1.8）的外部参照是 MLIR LICM 判定 + 分歧处 JIT A/B（values §12），毒值 tensor 操作数处偏保守。
- M5.3：alloca 逃逸未建模（拒发）；多块循环体不处理（报原因）；M5.1 的白名单差分（第 56 轮）只用整数 arith、scf.for 与不透明调用的程序族；tensor 管线只有 bufferize 一条。
- 值层未覆盖：浮点 tensor、memref 内容、cf 多块、scf.while、func.call、complex、超越函数（均判未知）。
- 递归、方言注册与版本、transform 方言、DataFlow、bytecode、WASM：coverage 里是 ✗。
